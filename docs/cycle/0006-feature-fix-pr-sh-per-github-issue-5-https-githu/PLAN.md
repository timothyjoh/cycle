## Task 2: Implement fallback in pr.sh

### Overview
Rewrite the merge section of `src/defaults/scripts/pr.sh` to capture the first-attempt stderr, branch on detection of the auto-merge-disabled signature, fall back to synchronous merge, and emit clean diagnostics on each failure mode.

### Changes Required
**File**: `src/defaults/scripts/pr.sh`
**Changes**: Replace lines 16–30 (current `gh pr merge … --auto`, poll, timeout-fail) with the captured-stderr + branching shape below. Lines 1–14 (shebang, env asserts, push, pr create, pr_number capture) unchanged.

```bash
# First attempt: try GitHub auto-merge. Capture stderr without losing
# the exit code under set -e by short-circuiting the assignment with ||.
rc=0
err=$(gh pr merge "${pr_number}" --squash --auto 2>&1 1>/dev/null) || rc=$?

if [ "${rc}" -eq 0 ]; then
  # Auto-merge enabled. Poll until merged or timeout (30 minutes).
  deadline=$(( $(date +%s) + 1800 ))
  while [ "$(date +%s)" -lt "${deadline}" ]; do
    state=$(gh pr view "${pr_number}" --json state -q .state)
    if [ "${state}" = "MERGED" ]; then
      echo "${pr_url}"
      exit 0
    fi
    sleep 10
  done
  echo "pr.sh: PR did not merge within timeout" >&2
  exit 1
fi

# Auto-merge failed. If the failure is the "auto-merge disabled for this
# repo" signature, fall back to a synchronous squash merge. Any other
# failure propagates as-is.
case "${err}" in
  *enablePullRequestAutoMerge*|*"Auto merge is not allowed for this repository"*)
    if gh pr merge "${pr_number}" --squash --delete-branch; then
      echo "${pr_url}"
      exit 0
    fi
    fallback_rc=$?
    echo "pr.sh: auto-merge failed: ${err}" >&2
    echo "pr.sh: immediate-merge fallback also failed (exit ${fallback_rc})" >&2
    exit 1
    ;;
  *)
    echo "${err}" >&2
    exit "${rc}"
    ;;
esac
```

Notes:
- `rc=0; err=$(…) || rc=$?` keeps `set -e` honest: the `|| rc=$?` swallows non-zero only for the assignment, and the explicit branch downstream consumes the value.
- `2>&1 1>/dev/null` discards `gh`'s stdout (the auto-merge command has no contractual stdout in this script) and routes only its stderr into `err`.
- The fallback's success path echoes `pr_url` to stdout — single-value contract preserved (`commit.sh`/`pr.sh` convention).
- The non-matching error path uses `exit "${rc}"` (not `exit 1`) to surface the original `gh` exit code, matching SPEC's "no silent retry" / "original stderr visible" requirement.
- Both diagnostics on the fallback-failure path carry the `pr.sh:` prefix per the script-stderr-labeling convention (`src/defaults/scripts/commit.sh:50`, `src/defaults/scripts/pr.sh:29` precedent).
- `set -euo pipefail` retained verbatim at line 4. No `set +e` toggling — all error-suspension is local to the single `|| rc=$?` idiom.

## Risk Assessment

- **`set -e` interaction with captured stderr**: The `rc=0; err=$(…) || rc=$?` idiom is the standard bash pattern but easy to get wrong — e.g. omitting `rc=0` causes an unbound-variable trip under `set -u` on the success path. Mitigation: explicit initialization in the snippet above; source-shape test ensures the `gh pr merge … --auto` call is still present.
- **Detection-token brittleness**: GitHub could reword the human-readable error. Mitigation: the `case` glob matches *either* token, and the underlying GraphQL identifier `enablePullRequestAutoMerge` is more stable than the human-readable text — having both is a belt-and-braces guard. If GitHub changes both, the script returns to today's behavior (hard exit), which is no worse than current.
- **Stdout contamination**: `2>&1 1>/dev/null` is order-sensitive — reversed order would swap streams. Mitigation: builder copies the snippet verbatim; reviewer eyeballs the redirection order; the "fallback success echoes `pr_url`" assertion catches gross stdout regressions.
- **`--delete-branch` race vs. the poll loop**: Only relevant if both paths ever run for the same PR. They are mutually exclusive in the new control flow (auto-merge `rc==0` → poll branch; `rc!=0` → fallback branch). No risk in practice.
- **`.cycle` drift**: A builder who edits `src/defaults/scripts/pr.sh` but forgets `npm run sync-defaults` would leave `.cycle/scripts/pr.sh` stale and the next cycle would still hit the bug. Mitigation: Task 3 includes the explicit `diff -q` check; cycle 0005 byte-equality test (if present at the workflow level) provides a backstop.
