# Research: Cycle 0058

## Cycle Context
SPEC asks for an engine-side post-condition guard in `src/engine/run-cycle.ts`: after `writeFile(SPEC.md, sanitizeArtifactStdout(r.stdout))` for a `step.name === "spec"` step that returned `r.status === "ok"`, measure the sanitized UTF-8 byte length. If `< SPEC_MIN_BYTES` (target 200), mutate the step result to `failed` with greppable stderr `spec post-condition failed: <abs-path> is <N> bytes (< <THRESHOLD>)` so the existing failed-step branch terminates the cycle. One regression test under `tests/engine/` covers empty / under-threshold / at-threshold (strict `<`), against both branch-based and `no_branch:true` workflows.
