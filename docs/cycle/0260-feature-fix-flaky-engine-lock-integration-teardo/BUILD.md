**Failure modes handled**: (a) the transient descendant-write race — `rm` now retries the codes Node's `fs.rm` is documented to retry (`EBUSY`/`EMFILE`/`ENFILE`/`ENOTEMPTY`/`EPERM`) up to `maxRetries: 10` with `retryDelay: 50` ms (≈500 ms bounded budget), removing the directory once the lingering `run-one`/`sleep` descendant has finished writing, instead of throwing on the first `rmdir`. (b) Genuinely un-removable directory (non-transient, or a transient that persists past the budget) — `rm` still throws after retries are exhausted; **no `try/catch` was added** to any `finally`, so a hard teardown error propagates and the `node:test` runner surfaces it as a failed test. The fix suppresses only the documented transient codes and never silently swallows a real teardown error. No new test case is added: synthesizing a reliably-stuck directory across platforms would itself be flaky, so the failure-path requirement is met by this recorded reasoning (per SPEC §Testing Strategy and the PLAN). Idempotency is preserved — `rm(..., { recursive: true, force: true })` already tolerates a missing path (`force` suppresses `ENOENT`), and re-running teardown remains safe; the retry options do not alter that.

**Option-3 finding (orphaned descendant / signal-propagation)**: the observed `ENOTEMPTY` is a **test-teardown-ordering race, not a production signal-propagation defect**. The supervisor's SIGTERM/SIGINT handlers (`src/cli.ts:201-216`) exit and release the lock but do not explicitly kill the non-detached `run-one` child (`spawnRunOne`, `src/cli.ts:420-447`) or its non-detached `sleep 30` bash grandchild (`execBashStep`, `src/engine/exec-bash.ts:28-32`); the existing assertions already prove the supervisor exits and the lock is removed. The descendant simply outlives the awaited supervisor exit and can write into `root` while `rm` runs. No production fix is shipped or required this cycle; if a production process-group teardown is later wanted it is **deferred to a named sibling cycle** (none filed here — the test hardening fully resolves the observed flake).
